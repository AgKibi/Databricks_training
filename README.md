# Databricks_training

Welcome to the **Databricks Training Course** repository!

This repository contains all the source code used in the Databricks course. Here you will find the notebooks, examples, and exercises covering the topics taught throughout the course, including:

* Databricks notebooks and workspace basics
* Apache Spark (PySpark, SQL, Scala) fundamentals and data engineering
* Delta Lake and Unity Catalog
* Machine learning and MLflow on Databricks

Feel free to clone the repository, explore the notebooks, and follow along with the course material.

**Happy learning!**
